# AI Multi Ask 1.2.0

在 Chrome / Edge 侧栏统一向 ChatGPT、Gemini、Qwen、DeepSeek 提问、分发附件，并将多方意见统合成可下载报告。通过已登录网页工作，不需要 API Key。

## 更新后先做这三步

1. 在 `edge://extensions` 或 `chrome://extensions` 找到 AI Multi Ask，点击“重新加载”。首次使用则开启开发者模式，加载本目录。
2. **刷新已打开的 AI 网页，再关闭并重开侧栏**，使旧内容脚本退出。
3. 点击“打开选中网站”，登录后“刷新状态”，再点击 **“读取实际模型”**。

模型切换、附件接收和统合导出的自动化测试已通过；由于本次无法连接用户已登录浏览器，**四个线上网站的账号实际可用性尚未验收**。遇到未确认结果会报错，不会假报成功。详见 [验证记录](VALIDATION.md)。

## 实际模型与模式

旧版 GPT-4o、Gemini 1.5、Qwen-Max 等固定下拉选项已移除。点击“读取实际模型”后，扩展会读取当前网页的模型菜单，将实际名称列在对应平台下；不可用的选项禁用。新模型不需要手工写进一份固定清单。

- 选择一个选项会立即尝试在网页切换，并检查选中状态或模型按钮文字；**确认失败时恢复原选择并提示错误**。
- 当前网页具备 `aria-pressed` / `aria-checked` 状态的深度思考、搜索开关，也会列为明确的开启/关闭选项。
- “沿用网页当前模型”不会更改网页模型和开关。
- 读取到的选项保存为本机缓存；账号、页面或网站更新后应重新读取。缓存不是可用性保证，每次发送仍会验证指定选项。
- 如果没有读到选项，可先在网页手动展开模型菜单，再点击读取。纯滑块、特殊组件或页面改版可能需要进一步适配。

当前官方说明及读取策略见 [模型核对记录](MODELS.md)。

## Gemini 默认第二个账号

默认打开 `https://gemini.google.com/u/1/app`。升级至 1.2.0 时会把旧设置迁移为第二个账号，并重置旧模型选择；之后用户自行修改的账号偏好会保留。

选择第二个账号时，只匹配 `/u/1/` 页面；只有第一个账号页面打开时，会要求打开第二个账号，不会静默发送给第一个账号。原有对话不会被强制重定向。**扩展不能替你创建登录会话**；如果第二个账号尚未登录，需在 Google 网页完成登录。账号序号按浏览器当前 Google 账号顺序确定。

## 文件和图片

点击 **“添加文件 / 图片”** 可选择最多 5 个附件，总计 20 MB。这是扩展本身的传输上限，网页可能有更严格的类型或大小限制。

1. 选择文件后在侧栏核对文件名，可逐个移除。
2. 点击填入/提问时，附件只发送到勾选的平台。
3. 扩展匹配网页实际 file input 的 `accept` / `multiple`，传输真实文件字节，并等待网页附件卡片出现及可见上传进度结束。
4. 45 秒内无法确认或网页提示错误时，停止该平台发送并说明原因；其他平台独立处理。

“仅填入”也会上传所选附件，但不点击发送。若网页未提供匹配的上传入口，可先在网页打开附件菜单后重试。部分网站不会显示原文件名，当前保守确认机制可能要求人工查看。检测到同一附件仍在网页的 file input 中时会阻止重复上传；确认网页已上传后，可以从侧栏移除附件再继续发送。

附件原件仅保留在当前侧栏内存，不写入扩展存储；关闭侧栏后需重新选择。全部选中平台确认发送成功后清空附件队列。附件上传到网站后的存储行为遵循对应网站政策。

## 一键多意见统合报告

获得至少两个 AI 的回答后，选择“统合 AI”，点击 **“统合各方意见并导出”**。

- 对勾选平台的原问题、独立后缀、回答、模型选择、附件名和错误状态建立快照，保留各平台原文。
- 将这些回答文字发送给选定的统合 AI，在其当前对话继续生成综合答案；原附件不会再次上传给统合 AI。
- 提示统合 AI 输出：可直接使用的综合结论、每个 AI 说了什么、共识、分歧及理由、待核实事项、建议行动，并按平台标注来源。
- 原始问题不一致时要求分题处理；无回答的平台注明缺失，不编造观点。AI 生成的统合仍需根据原文审阅。
- 完成后自动下载 **Markdown 报告**，包含综合答案和各 AI 原文附录。最近一次成功报告保存在本机，可点击“再次导出统合报告”。

统合最多监听 10 分钟；失败、超时或空回答不会导出为最终报告。保持侧栏打开直到完成。统合消息使用单独请求 ID 和原文快照，不覆盖下方各 AI 的原始回答。网页生成状态识别依赖适配器，长时间停顿或页面改版可能影响完成判定。

## 其他功能

草稿恢复、预设模板、最近 30 条提示词历史、平台独立后缀、单栏/并排对比、手动刷新回答、复制和原文 Markdown 导出均保留。快捷键 Ctrl+Enter 执行当前填入/发送模式；Ctrl+Shift+A 打开侧栏，冲突时可在浏览器扩展快捷键页修改。
